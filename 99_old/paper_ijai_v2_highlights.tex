\section*{Highlights}
\begin{itemize}
\item A weakly supervised pipeline localizes durian leaf lesions without manual masks.
\item GradCAM++ percentile thresholding gives controllable class-aware pseudo-labels.
\item SAM refinement improves IoU from 0.5135 to 0.6239 under a controlled comparison.
\item Pseudo-label-dependent metrics are shown to be non-comparable across versions.
\item A SAM mask-expansion failure mode is analyzed for transparent benchmarking.
\end{itemize}
